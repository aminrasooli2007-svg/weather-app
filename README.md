# 🌦️ Atmos — Weather App

A modern, animated weather application built with **React** and **Tailwind CSS**, featuring real-time weather information, hourly forecasts, and a 5-day weather outlook.

## ✨ Features

- 🌍 **City Search** — Find weather conditions for cities around the world.
- 🌡️ **Current Weather** — View temperature, feels-like temperature, humidity, wind speed, and precipitation.
- 🕒 **Hourly Forecast** — Explore upcoming hourly weather conditions.
- 📅 **5-Day Forecast** — Check daily minimum and maximum temperatures.
- 🌅 **Sunrise & Sunset** — View local sunrise and sunset times.
- 🎨 **Modern UI** — Glassmorphism, animated backgrounds, and smooth transitions.
- 📱 **Responsive Design** — Optimized for desktop and mobile screens.
- 🔄 **Refresh Weather** — Update the latest available weather information.

## 🛠️ Built With

- React
- JavaScript (ES6+)
- Tailwind CSS
- Vite
- Lucide React
- [Open-Meteo API](https://open-meteo.com/)

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/aminrasooli2007-svg/weather-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd weather-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🌐 Weather Data

Weather information is provided by [Open-Meteo](https://open-meteo.com/). The application uses its geocoding service to search for cities and its forecast API to retrieve weather data.

No API key is required for the public endpoints used by this project.
